
# Projeto para estdudos nas Disciplinas de Acessibilidade e Otimização de Buscas

## Fatec Taquaritinga  - 1 Semestre 2025


Meyer Reset CSS é um arquivo CSS que redefine os estilos padrão dos elementos HTML. Ele remove as margens, paddings e outros estilos padrão que os navegadores aplicam aos elementos. O objetivo do Meyer Reset CSS é garantir que todos os elementos tenham um ponto de partida consistente, independentemente do navegador utilizado. Isso facilita a estilização e a criação de um layout responsivo.
